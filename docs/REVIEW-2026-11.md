# HaitiViral expert review (November 2026)

Six reviewers analyzed the whole site on a local test copy, with fake money and fake providers:
- feature builder (developer)
- 2 UI experts: customer screens, admin screens
- 2 UX experts: main customer journeys; other flows + owner workflows
- security expert

Nothing was changed by the review. Findings below are combined, de-duplicated and ranked. The number of reviewers who found the same thing is shown in brackets.

---

## Phase 1: fix before real customers (money, security, broken install)

| # | Problem | Why it matters | Reviewers |
|---|---|---|---|
| 1 | **Pack refunded twice.** A failed line refunded alone, then the whole order refunded, pays the line back a second time. The 96 h auto-refund can do it with no person involved. | Free money for customers, repeatable | builder |
| 2 | **Outdated Next.js with a critical security advisory**, plus other vulnerable packages (`npm audit`: 3 critical, 9 high) | Known attack on the image optimizer | security |
| 3 | **VPS install script makes the encryption key in the wrong format** (`openssl rand -hex 32`, but the app expects base64) | On a fresh VPS, provider keys can't be saved and account deliveries fail. Not yet used, so no live damage | security (confirmed) |
| 4 | **Free trial refused by the provider gets stuck forever.** A refund of 0 fails, and the order blocks the auto-refund queue (50 at a time, no order) | Real paid orders may never be auto-refunded | builder |
| 5 | **Paid order never sent after a restart or notify error.** Nothing re-sends PAID orders; they wait 4 days for the auto-refund | Customer charged, nothing happens | builder |
| 6 | **Lost connection at "Konfime" / deposit.** The whole screen becomes "Gen yon pwoblèm", everything typed is lost, and the NatCash reference is wiped after any error | Customer can't tell if the money left. Happens on slow data, exactly when paying | ux-core |
| 7 | **Harmful-code risk (XSS) in news/FAQ/home structured data.** A content editor can run code on every visitor's page; there is no CSP | Could steal referral withdrawals or wallet money | security |
| 8 | **Staff can enter the admin without 2FA** (Google sign-in, auto sign-in after email verification) | Takeover of a staff Google account gives admin access | security |
| 9 | **Trick link to a fake MonCash page.** Users can set any "language", and the MonCash return page redirects with it. Name, phone and picture are also unchecked | Phishing for MonCash PINs | security |
| 10 | **Delivered account passwords readable in the provider log**, and the logs go into backups | Defeats the encryption | security |
| 11 | **One finance staff member can approve a fake deposit alone.** No step-up and no second person, unlike wallet adjustments | Insider money creation | security |
| 12 | **SMM line stuck in "UNKNOWN" can never be re-sent.** Only "Close" or a refund is possible | Common with provider timeouts | builder |
| 13 | **Double tap can create two orders** (the same-link check is outside the transaction) | Double charge on slow data | builder |
| 14 | **Late MonCash payment lost after 24 h.** The intent expires, then the credit is refused; polling is in random order | Customer paid, wallet not credited | builder |
| 15 | **Step-up 2FA code can be guessed without limit** | Weakens admin protection | security |
| 16 | **Backups are readable by any user on the server**, unencrypted and on the same disk | Data loss and leaks | security, builder |

## What reviewers said is already good

- **Money system.** The wallet ledger is double-entry with a database balance check, idempotency keys and no negative balances. MonCash credits only after MonCash's own confirmation. Customers can only see their own orders, tickets and codes.
- **Provider orders.** An order that may already exist at the provider is never re-sent by itself; YTSeller retries are safe; prices are computed on the server; products pause themselves at a loss.
- **Design.** Clean, modern light design; well-structured order flow; excellent live link checker in Kreyòl; honest refund explanations.
- **Admin on phone.** Bottom bar with badges; tables turn into cards.
- **Delivered accounts page.** Copy buttons, live 2FA code, safety guide, warranty date.
- **Ops.** One-command Docker install with HTTPS, swap, firewall and backups.
