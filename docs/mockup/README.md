# HaitiViral mockup

Clickable design mockup (13 screens: 10 customer phone screens + 3 admin screens).

- Live version: https://claude.ai/artifact/L3Ld2sihR9pTGiVpC4ubBE (private to the owner; open a screen and press Play)
- `canvas.json` lists the screens and their layout; each `*.dc.html` file is one screen.

All prices, names and numbers in the mockup are examples, except the admin risk counts and provider service names, which come from a real test on one provider's public service list (2026-10-21).
